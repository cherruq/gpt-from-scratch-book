# 逐章数学与数值审校

2026-11-26。逐章对照正文、附录、源码和运行入口。表中列出手算主例及补查的数值，公式的成立条件、归约轴、交叉引用和语言表述另行人工检查。开放题的实验设计与硬件耗时属于复查材料，耗时不设固定数值断言。

- 新增重点算例由 tests/test_worked_examples.py 断言，运行时读取 examples/ 下的同一源文件。
- 主例与习题的补充数值由 tests/test_chapter_audit.py 和各专题原有测试复核。
- scripts/check_examples.py 除复跑各章入口及版本 ZIP 外，将两套 CPU 验证曲线、解释性实验的概率和注意力行与本仓库记录比较。
- 整数数组、形状和参数量精确比较。手算小数按展示精度取绝对容差，有限差分步长 \(10^{-5}\) 或 \(10^{-6}\) 并使用正文给出的误差阈值。浮点同后端的恢复比较使用逐元素精确相等。
