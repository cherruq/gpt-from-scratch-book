# 从上下文学习语义

## 学习目标

构造共现矩阵，比较 CBOW 和 Skip-gram，推导负采样梯度并观察学到的词向量。

## 前置知识

[[04|第 4 章]] 的相似度、[[10|第 10 章]] 的概率损失、[[18|第 18 章]] 的查表。

## 本章在 GPT 中的位置

Word2Vec 是理解分布式词向量的教学桥梁。GPT 的输入嵌入由下一 Token 目标联合训练，每个位置的深层状态又随前缀变化。

## 计数与预测

指定窗口半径 \(r\)，若某中心词和窗口内的邻词一起出现，就令共现矩阵 \(C_{ij}\) 增加 1。逐行归一化可估计邻词分布，但矩阵形状 \([V,V]\)，稀有词估计不稳。CBOW（连续词袋）汇总邻词向量再预测中心，标准词袋汇总弱化了顺序。Skip-gram 用中心词向量分别预测相邻词。原始词向量实验使用了更大语料与更多训练策略，本书只实现小型 Skip-gram 负采样。[Word2Vec 原论文](https://arxiv.org/abs/1301.3781v3) · [负采样原论文](https://arxiv.org/abs/1310.4546v1)

## 从分词结果逐位置数共现

接着用 [[17|第 17 章]] 的字节级 BPE。训练记录是「春春」和「春」，合并上限为 2。两条记录的 ID 分别为 \([256,259,259,257]\) 和 \([256,259,257]\)。以下例子将 BOS、EOS 都计入窗口，记它们为 \(B,E\)，春为 \(S\)。

对每条记录，枚举中心位置 \(t\) 与邻居位置 \(s\)。两者必须在同一条记录内，并满足 \(0<|s-t|\le r\)。共现矩阵的行是中心 ID，列是邻居 ID：

$$ cooccurrence-count
C_{ij}=\sum_{\text{记录 }x}\;\sum_t
\sum_{\substack{0\le s<|x|\\0<|s-t|\le r}}
\mathbf{1}[x_t=i]\mathbf{1}[x_s=j].
$$

条件排除的是中心**位置**，因此站在「春春」的第一个「春」，仍可数到右侧另一个「春」。半径 1 时，一个相邻位置对贡献两个有向事件。例如第一条记录的中间一对分别贡献 \(S\to S\)、\(S\to S\)，两次加到同一格。第一条有三个相邻位置对，第二条有两个，所以总计 10 个有向事件。

| 半径 1 的非零格 | 有向计数 |
| --- | ---: |
| BOS → 春 | 2 |
| 春 → BOS | 2 |
| 春 → 春 | 2 |
| 春 → EOS | 2 |
| EOS → 春 | 2 |

这里的对称窗口使 \(C_{ij}=C_{ji}\)。从「春」出发得到 6 个邻居事件，BOS、春、EOS 各分到 \(1/3\)。[[20|第 20 章]] 的下一 Token 计数只取右侧相邻位置，同一训练集会得到有方向的表。

CBOW 用窗口中多个邻居预测一个中心。例如第一条记录的第一个「春」看到 BOS 与另一个「春」，求均值时用 \((E_B+E_S)/2\) 作为输入。交换两个邻居的位置，均值不变。Skip-gram 则用这个「春」的中心向量分别预测两个邻居，一次产生 \(S\to B\)，另一次产生 \(S\to S\)。这两种训练都支持用双侧上下文塑造静态词向量。GPT 的下一项损失只用目标左侧的前缀作为条件。

## 负采样的梯度

中心表与上下文表各为 \([V,D]\)。对一条中心 \(u_i\) 和 \(K+1\) 条候选 \(v_j\)，沿 \(D\) 点积得到分数 \(s_j\)，正样本 \(y_j=1\)，噪声样本 \(y_j=0\)。负采样优化二元对比目标：

$$ negative
L_j=\log(1+e^{s_j})-y_js_j,\qquad
\frac{\partial L_j}{\partial s_j}=\sigma(s_j)-y_j.
$$

中心梯度为 \(\sum_j(\sigma(s_j)-y_j)v_j\)，候选梯度为 \((\sigma(s_j)-y_j)u_i\)，若对多项取平均再统一缩放。各行通过散射加更新。同一个训练上下文可以在噪声抽样中被抽到，有限数据里会给同一对矛盾监督。这里有意保留此现象，并用固定负样本集合比较优化前后的损失。由此学出的分数不自动构成词表上归一化的概率。

实现对上下文列求和得到 \(f_j=\sum_i C_{ij}\)。它用 \(f_j^{3/4}/\sum_k f_k^{3/4}\) 抽取噪声，上式的 \(f_j\) 具体指生成的有向对中的上下文出现次数。本例只有 \(B,E,S\) 的次数非零，分别为 \(2,2,6\)。所以噪声落在「春」的概率是 \(6^{3/4}/(2\cdot2^{3/4}+6^{3/4})\approx0.532656\)，两个边界项各约 0.233672。一个中心可能抽到重复负例，也可能抽到当前正例。每个正对固定抽 3 个负例，120 步优化期间不重新抽取，平均损失的分母是全部正负候选数。

## 手算标准分数

若真实对分数为 0，负例分数也为 0，则单项损失均为 \(\log2\)，导数分别为 \(-0.5,+0.5\)。在平均两个样本的损失中两项梯度再除以 2。若中心 \([1,0]\)，两条候选先设成 \([0,1]\)、\([0,-1]\)，中心梯度是 \([0,-0.5]\)，正候选向中心方向移动，负候选反向移动。

再令第一个候选行 \(v_0=[0,1]\) 既是真实邻居，又被抽为一个负例，另一个负例行仍为 \(v_1=[0,-1]\)。候选索引是 \([0,0,1]\)，标签是 \([1,0,0]\)。三个分数仍都为零，均值损失仍为 \(\log2\)，分数梯度分别为 \([-1/6,1/6,1/6]\)。

- 中心行接收三个方向贡献，\((-1/6)v_0+(1/6)v_0+(1/6)v_1=[0,-1/6]\)。
- \(v_0\) 被读取两次，两份梯度 \((-1/6)[1,0]\) 和 \((1/6)[1,0]\) 相抵，梯度是 \([0,0]\)。
- \(v_1\) 只收到 \((1/6)[1,0]=[1/6,0]\)。

差分时扰动表里的 \(v_0\) 行，两个使用位置的分数必须一起变。对于上面全部 6 个参数，float64 中心差分以 \(10^{-5}\) 为步长，实测最大误差 \(1.09\cdot10^{-12}\)，验收绝对阈值 \(10^{-10}\)。

## Python 实验

M3，运行 `python -m examples.language 19`。实验用三个短序列构建共现，ID 0 与 ID 1 都以 ID 2 为邻居。用 `src/math_basics/language.py::skipgram` 训练 120 步，固定噪声数据上损失约 0.69702 → 0.32296，输入表中 0 与 1 的余弦 0.89308，0 与 3 为 0.32674。该对比的对象是三个合成序列。

M3-v3 的共享实验输出完整共现计数、噪声概率与负采样复算。默认两条短记录和固定噪声下，损失从 0.688452 降到 0.452672。损失衡量这组正负配对上的二分类拟合。

## 常见错误

- 把对样本二分类的 Sigmoid 概率解释成词表条件概率。
- 只公布训练后挑选出来的相似词对；应先定义测量对。
- 用同一个静态向量描述一个词在所有上下文中的角色。

## 练习

1. **基础。** 半径 1 下，序列 [0,2,0,2] 的 \(C_{0,2}\) 取值是多少？
2. **推导。** 对 \(L_j\) 直接求导。
3. **工程。** 改用半径 2，重新打印计数和余弦。
4. **开放探索。** 如何区分词向量反映语义还是只反映词频？

<details markdown="1">
<summary>参考答案</summary>

1. 第 0 个位置贡献 1，第 2 个位置贡献 2，共 3。
2. 指数与对数的链式法则得 \(e^{s}/(1+e^s)-y\)。
3. 半径 2 增加距离两步的邻居，包括本例中的同类 ID；固定种子检查分数变化。
4. 加入频率匹配的对照词，先固定相似度评估集并比较多个随机初始结果。
