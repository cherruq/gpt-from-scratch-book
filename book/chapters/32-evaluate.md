# 评估与调试

## 学习目标

读懂训练曲线，按有效 Token 计算验证 NLL 与困惑度，从定位梯度问题到辨别记忆与泛化。

## 前置知识

[[07|第 7 章]] 的差分、[[10|第 10 章]] 的困惑度、[[24|第 24 章]] 的因果性和[[31|第 31 章]]的采样。

## 本章在 GPT 中的位置

检查应分层进行。让单个算子正确，再让同批优化正确，最后才看留出验证。单次生成只是一种行为观察。

## 诊断顺序

1. 核对 Token ID、标签偏移、相同样本的 \([B,T,V]\) 行与目标。
2. 对批中所有前缀替换未来，比较早期 logits。
3. 对单算子和模型的几个权重做 float64 中心差分。步长取 \(10^{-6}\) 或 \(10^{-5}\)，避免不可导点并记录绝对和相对误差。
4. 单批过拟合，确认 Loss 下降且权重有非零变化。记下裁剪前范数，若更新全零，排查梯度清空、学率和参数引用。
5. 才开始看独立验证。通过 NaN、无穷或掩码全空的检查把数值问题定位到确切层和样本。重点复核 Softmax 稳定实现与标签索引。

定义对 \(n\) 个有效目标的指标：

$$ evaluation
\operatorname{NLL}=-\frac{\sum_{i=1}^n\log p_\theta(y_i\mid x_{<i})}{n},
\qquad \operatorname{PPL}=\exp(\operatorname{NLL}).
$$

例如两个批次分别含 3、1 个有效目标，批均损失为 1、3，则全体平均为 \((3\cdot1+1\cdot3)/4=1.5\)，困惑度 \(e^{1.5}\approx4.48169\)。直接平均批损失会得到 2，偏高。此原则也适用于屏蔽填充目标的批量。

## 用成对输入测量上下文是否起作用

固定一个四行训练批。每行向右移一项得到监督目标，末位输入都为 6，正确答案由首项决定。

| 输入 | 目标 | 末位答案 |
| --- | --- | ---: |
| [0,2,6] | [2,6,4] | 4 |
| [1,2,6] | [2,6,5] | 5 |
| [0,3,6] | [3,6,4] | 4 |
| [1,3,6] | [3,6,5] | 5 |

只读当前位置 ID 的模型在四行末位输出同一个分布。记 \(p_4,p_5\) 为分给两个正确类别的概率，由 \(p_4+p_5\le 1\) 和算术–几何平均不等式得到 \(p_4p_5\le ((p_4+p_5)/2)^2\le 1/4\)。代入两类各出现两次的平均负对数似然：

$$ context-floor
\operatorname{NLL}_{\rm last}=-\tfrac12\log(p_4p_5)\ge\log 2\approx0.693147.
$$

该模型在末位的 greedy 答案也固定，最多答对 2 行。能读取整个前缀的因果模型可以判断末位答案。它仍会在位置 0 遇到不确定性，看到 0 或 1 时，下一项各有一次为 2、一次为 3。对这四个目标重用上述计算，得到总 12 个目标的平均 NLL 下界 \(4\log 2/12\approx0.231049\)。位置 1 的答案恒为 6，位置 2 的答案可由首项判断，这八项的损失可以趋于零。

[[40|第 40 章]] 的默认实跑结果是总 NLL 0.232363、末位 NLL 0.001164，按顺序答对 4、5、4、5。这个测量描述同一训练批的上下文拟合。复查时仍须替换未来输入并比较前缀 logits，防止模型提前看见位置 0 的答案后把总 NLL 压到因果下界以下。

## 常见错误

- 用一个采样样例判定模型是否学会任务。
- 比较不同 tokenizer 的每 Token 困惑度，忽视分母不同。
- 用大容差掩盖梯度反向错误，或只在梯度接近零时用相对误差。

## 练习

1. **基础。** 一半目标损失 1、另一半损失 3，整体困惑度是多少？
2. **推导。** 为什么算术平均批 PPL 一般不等于总 PPL？
3. **工程。** 添加命中和未命中嵌入行的差分。
4. **开放探索。** 在成对实验里将中间项扩充为更多 ID，如何用留出的首项与中间项组合测试泛化？

<details markdown="1">
<summary>参考答案</summary>

1. 平均 NLL 2，PPL \(e^2\)。
2. 因为指数一般不与平均交换，且不同批的目标数可能不同。
3. 分别改共享表的元素，固定其他变量，检查哪条路径产生梯度。
4. 让每个首项和中间项都至少见于一条训练样本，保留若干未出现的配对。在训练与留出样本上分别算末位 NLL 和准确率。调整训练配对会改变位置 0 的经验条件分布，因此末位指标更直接衡量任务规则。
</details>
