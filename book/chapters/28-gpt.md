## 主路径与所有参数

| 计算 | 输入到输出 | 学习参数 |
| --- | --- | --- |
| Token 查表 | [B,T] 到 [B,T,C] | E[V,C] |
| 位置查表与加法 | [T,C] 跨 B 相加 | P[Tmax,C] |
| 块内 Norm ×2 | [B,T,C] 保持形状 | 每层 gain、bias 各 [C] |
| Q/K/V 和输出投影 | [B,T,C] → [B,H,T,D] → [B,T,C] | 4 组 [C,C]、[C] |
| 块内 FFN | [B,T,C] → [B,T,F] → [B,T,C] | [C,F]、[F]、[F,C]、[C] |
| 最终 Norm | [B,T,C] 保持形状 | [C]、[C] |
| 输出 LM Head | [B,T,C] 右乘 [C,V] | E 的转置 |

块结构重复 \(L\) 次，每次有独立参数。投影矩阵及嵌入按种子抽自均值 0、标准差 0.02 的正态分布，偏置全零、Norm 增益全 1。输出无独立偏置。对数概率归约词表轴，损失再归约批与时间轴。参数规模和随机初值共同决定初始分布，随机模型的输出不保证精确均匀。

$$ parameter-count
N=VC+T_{\max}C+
L\big[4C + 4(C^2+C)+2CF+F+C\big]+2C.
$$

前向查表只读取命中的行。反向从交叉熵 [[10#ce-gradient]] 到输出头，将梯度分到最终 Norm 与嵌入表。随后逐块通过 FFN、残差、MHA、两次 Norm 回到输入状态。此处对两份相加输入的梯度相同，位置表沿批次相加，Token 表按输入 ID 散射相加。Token 表还合并输出头的稠密路径。两个路径对同一参数对象累加一次，再交给优化器更新一次。

## 手算 544 个参数

用 \(V=8,T_{\max}=4,C=4,H=2,D=2,F=16,L=2\)。Token 表 32，位置表 16；单块 Norm 16、注意力 80、FFN 148，合计 244；最终 Norm 8。总数 \(32+16+2\cdot244+8=544\)。若增加独立无偏置输出权重，就会多 32。批大小对参数数无影响。

### 追踪共享表的两个角色

在微型序列中，位置 0 的输入 ID 为 0、目标 ID 为 1。最终 Norm 输出行 \(z_0[1,C]\)，词表列 1 的分数是 \(\sum_c z_{0c}E_{1c}\)。位置 0 的输出不能通过注意力读取未来的输入 ID 1。输出头仍使用 \(E[1]\) 计算候选分数。前者是读取序列输入，后者是对每个词表候选打分。

单看这一位置，列 1 的直接上游为 \(p_1-1\)，输出头对 \(E[1]\) 贡献 \((p_1-1)z_0\)。同一位置的输入路线只给 \(E[0]\) 加一项。若 ID 1 在另一位置真实出现，那里又会给 \(E[1]\) 累加输入梯度。参数表只注册一次，才会把两个路径累加到同一个被更新对象。

### 将共享表临时拆开做对照

设输入查表后的上游为 \(D_X[B,T,C]\)，最终隐状态展平为 \(Z[BT,C]\)，logits 的上游展平为 \(U[BT,V]\)。共享表的两项梯度为

$$ tied-gradient
(\overline E_{\rm in})_{vc}=\sum_{b,t:\,I_{bt}=v}(D_X)_{btc},\qquad
\overline E_{\rm head}=U^\mathsf T Z,\qquad
\overline E=\overline E_{\rm in}+\overline E_{\rm head}.
$$

第一项只写实际命中的行。第二项沿 \(BT\) 归约；Softmax 的梯度通常涉及未出现在输入序列的候选，LM Head 可以更新那些行。含重复 Token 的轮换样本可同时暴露这两个现象。

做两次前向。第一遍用真实模型的共享表；第二遍用两份相同数值的独立叶子，分别接查表和输出投影。logits 与 loss 应一致，两叶子梯度之和应等于共享梯度。诊断后训练仍注册一份参数。固定输入 \([1,1,2]\)、标签 \([1,2,3]\)，两层模型的初始化种子为 42。第 1 行第 0 通道从输入路径取得约 \(-0.03089878\)，从输出路径取得约 \(0.32966901\)，合计 \(0.29877023\)。第 7 行未作为输入，其第 0 通道仍收到约 \(-0.07082213\) 的输出梯度。

运行 <code>python -m examples.attention_labs 28</code>（M5-v2）。除了两个抽查位置，还会比较全部 logits 和共享表梯度，后者最大误差约 \(5.6\cdot10^{-17}\)。

## 常见错误

- 统计参数时对共享嵌入算两遍。
- 将词表输出和隐藏宽度混淆，导致损失标签超范围。
- 将相同块对象装入列表多次，意外共享跨层权重。
