# 自动微分引擎

## 学习目标

实现标量和张量的反向模式自动微分，能解释拓扑、分支累加、广播还原和重复索引。

## 前置知识

[[08|第 8 章]] 的 VJP 与[[14|第 14 章]]的手写反传。

## 本章在 GPT 中的位置

NumPy GPT 的前向每做一次运算，引擎就记录从结果到活跃输入的反向规则。训练目标调用一次 `backward`，所有模型参数收到对应梯度。

## 计算图与调度

每次运算生成新节点并指向已有节点，因此得到有向无环图（DAG）。物理上可以有两条边指向同一变量，比如 \(x^2=x\cdot x\)。先深度遍历，到父输入后再把节点压入顺序表，反转得到从输出到输入的反向调度。一个节点仅调度一次，每一条边都提交贡献。标量输出种子为 1；向量输出传入同形状权重 \(g\) 等价于对 \(\langle g,y\rangle\) 求导。

$$ dag-gradient
\bar x=\sum_{y:\,x\to y}\operatorname{VJP}_{y,x}(\bar y).
$$

这里的和以运算输入槽位计。图中间量的累加容器每次反传重新创建，叶子存储的梯度跨调用累加。每个优化步先清空叶子梯度。前向与反向之间不要就地修改参数，闭包里要使用同一批数值。标量例子为每条边保存局部数值斜率，张量版本用接收上游数组的 VJP 闭包替代它。

## 张量基础规则

| 前向 | 反向 |
| --- | --- |
| 按轴求和 | 补回归约轴并广播上游 |
| 广播加法或乘法 | 先做局部乘积，再沿扩展轴相加 |
| reshape | 还原父输入形状 |
| transpose | 应用轴置换的逆 |
| gather | 将上游散射加到命中位置，重复索引累加 |
| exp、log | 分别乘前向输出、除原输入 |
| matmul | 使用 [[08#matmul-vjp]]，还原批广播 |

例如 \([B,T,C]\) 与 \([C]\) 相加，后者的梯度先归约两个前缀轴。若原轴存在且长度为 1，求和时保留轴。张量引擎限制 matmul 至少有两个显式矩阵轴，这使 VJP 无需额外处理一维向量升降轴。源文件的 `where` 在掩码之外反向置零；融合交叉熵通过 `Tensor.from_op` 直接接入自定义 VJP。

## 手算路径

\(x=2\) 时，\(y=x\cdot x+x=6\)。乘法的两个输入槽各给 2，加法直连提供 1，梯度为 5。张量例子 \(X=[[1,2],[3,4]],b=[2,3]\) 计算 \(\sum(X\odot b+X)=36\)。梯度 \(G_X\) 每行都是 \(b+[1,1]=[3,4]\)，\(G_b\) 为 \(X\) 两行之和 \([4,6]\)。

### 追踪张量引擎的每条边

活动边由 <code>from_op</code> 决定。例如 \(x+b\) 的前向是 NumPy 加法。\(b\) 为常量时只留 \(x\) 的边。若 \(b[C]\) 可训练，闭包调用 <code>unbroadcast</code> 沿缺失的首轴求和，将梯度还原为 \([C]\)。被求和的输入则相反，闭包恢复消失的轴，把上游值分给所有曾参与求和的元素。两个规则在线性空间里互为转置。

反传为当前调用创建映射保存每个节点收到的梯度。如果图的两条路线都指向 \(x^2\)，先反传离损失近的两支，再消费平方节点收到的总和。若永久存储所有中间梯度，重复调用时还要把中间值清零。本实现只让叶子永久累加。要检查独立算子的 VJP，先选择张量 \(u\) 作为上游，定义标量 \(f(x)=\sum u\odot\operatorname{op}(x)\)，再对 \(x\) 差分。固定 \(u\)，避免差分经过额外路径。

### 手算非标量反传与重复 Token

把嵌入表设为 \(E=[[1,2],[3,4],[5,6]]\)，索引为 \([1,1,0]\)。查表得到三行，再逐通道乘 \(s=[2,3]\)，沿位置轴广播，最后交换两个轴。输出 \(Y[2,3]\) 为 \([[6,6,2],[12,12,6]]\)。指定与 \(Y\) 同形的种子 \(G=[[1,2,3],[4,5,6]]\)，等价于比较标量 \(L=\langle G,Y\rangle=168\) 对叶子的影响。这里 \(G\) 固定，改变 \(Y\) 的某一项会按指定系数改变 \(L\)。

先过转置，取 \(G^\mathsf T[3,2]\)，得到 \([[1,4],[2,5],[3,6]]\)。反向经过逐通道乘法时，这三行各自乘 \(s\)，给查表输出的梯度为 \([[2,12],[4,15],[6,18]]\)。将第一和第二行加到 \(E_1\)，第三行加到 \(E_0\)，没命中的 \(E_2\) 接收零：

$$ seeded-gather
\overline E=\begin{bmatrix}6&18\\6&27\\0&0\end{bmatrix},
\qquad
\overline s=\sum_{i=0}^2 G^\mathsf T_{i,:}\odot E_{\mathrm{id}_i,:}=[12,48].
$$

若再对原图用同一个种子反传，第三行仍是 0，\(E_1\) 的梯度变成 \([12,54]\)。原因是叶子存储跨调用累加，非叶子的中间梯度则重新计算。训练每步要在反传前清理叶子梯度；主动做梯度累积时，则要按多个微批的有效目标数选择正确权重。

用对象身份做拓扑访问避免值碰巧相同的节点被合并。图节点可去重调度，但一旦同一个叶子出现在输入的两个槽位，两个槽位的反向都必须走。常量即使不记录反向边，反向闭包可能仍读到它的值，例如乘法需要另一侧的输入。在此教学引擎中，直到反传结束且下一步将重建图之前，前向用到的数组和索引都应视为只读。

## 常见错误

- 用输入值判定节点相等，错误合并两个碰巧数值相同的参数。
- 跳过相同父节点的第二个槽，漏掉平方的一半梯度。
- 使用 NumPy 的 `gradient[ids] += values` 作为重复索引散射，每个命中未必都能参与累加。
